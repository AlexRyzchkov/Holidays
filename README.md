# Holidays

## О чём проект? 
Цель проекта - создать программу, которая знает все праздники.

## Описание работы программы:
Программа импортирует библиотеку holidays. Далее, с помощью переменной ru_holidays, программа настроится на поиск праздничных дней России. Пользователь вводит в консоль интересующую его дату в формате ГГГГ-ММ-ДД. Если на этот день выпадает официальный праздник, то программа выведет его название. Если данный день не является праздничным, выводится: "Праздника в этот день нет".
